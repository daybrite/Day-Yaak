# Vector glyphs

The toolbar glyphs are [Material Symbols](https://fonts.google.com/icons) (Outlined, weight
400, 24 px), copied from Google Fonts as single-path SVGs and renamed for what the app uses
them for. Day stages them as template glyphs, so each toolkit tints them to its own bar.

| File | Material Symbol | Used for |
|---|---|---|
| `layout_stack.svg` | `dock_to_bottom` | the layout button while the response is beside the request (press to stack it) |
| `layout_beside.svg` | `dock_to_right` | the layout button while the response is under the request (press to put it beside) |
| `send.svg` | `send` | Send |
